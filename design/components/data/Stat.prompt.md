Big expanded-display number with mono unit and delta — the "one number that matters" in a widget. Counts up on mount.
```jsx
<Stat label="Gastado" value={1284.5} decimals={2} unit="€" delta="-8 %" deltaTone="up" caption="vs agosto" />
<Stat label="Peso" value={78.2} decimals={1} unit="kg" size={56} />
```
