Renders any Lucide icon (1.5–2px stroke line icons) tinted with currentColor via CSS mask — use for every glyph in Polaris.
```jsx
<Icon name="film" size={16} />
<Icon name="wallet" color="var(--accent)" />
```
- `name`: any lucide-static v0.460 icon name. Size 14/16 in dense UI, 18–20 in nav/headers.
