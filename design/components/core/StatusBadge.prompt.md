Shows an Odisea entry state (PENDIENTE / EN_CURSO / TERMINADO / ABANDONADO) — shape AND colour coded so it scans in dense lists.
```jsx
<StatusBadge estado="EN_CURSO" />
<StatusBadge estado="TERMINADO" variant="dot" />
<StateGlyph estado="ABANDONADO" />
```
- Glyphs: ring (pendiente) · half (en curso) · full (terminado) · struck ring (abandonado).
